# 0.4.0 — experimental pre-release

Dictionary definitions now follow the subtitle target while retaining supported English source explanations. Chinese target shows Chinese + English; English target shows one English section; other targets show an honest unsupported notice + English. Only English source words are supported. The interface stays Simplified Chinese.

Old vocabulary and handwritten notes remain compatible. Language changes cancel pending lookup and isolate caches. No new permission, provider, paid API or subtitle/vocabulary upload.

Assets: YouTube-Dual-Subtitles-Extension-0.4.0.zip (load extension folder), YouTube-Dual-Subtitles-Source-0.4.0.zip (source/tests/docs), SHA256SUMS.txt.

54 local unit tests, 24 isolated UI groups. Anonymous live dictionary queries are separate from extension validation. Installed Chrome/Edge, first real video/autoplay, native fullscreen, actual pause precision and browser-restart persistence remain outstanding. Manual native CC priming may still be needed. This release does not claim stability or CI/Linux verification.

Keep the existing unpacked extension identity, replace its files, reload, refresh YouTube, click the icon and confirm 0.4.0. Do not uninstall merely to update. Code MIT; Wiktionary definitions retain article attribution and CC BY-SA 4.0 terms.
