# 安装 / 更新

1. 下载 Release 的 YouTube-Dual-Subtitles-Extension-0.4.0.zip，解压到固定文件夹。
2. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。自行开启开发者模式，选择“加载已解压的扩展程序”，选中含 manifest.json 的 extension 文件夹。安装与授权由你控制。
3. 打开可访问的 www.youtube.com/watch 视频，点击扩展图标。设置底部确认版本 0.4.0。
4. 设置中选择原文轨及译文目标。默认原文下、译文上；拖动模式显示位置示例，关闭设置恢复真实字幕。
5. 点击英文词暂停并查词；主释义语言跟随字幕目标，不支持的目标会明确提示。主动保存笔记与收藏。
6. 点击 ×、关闭按钮或扩展图标退出，清理覆盖层和计时并恢复临时调整的原生 CC。

更新保留原有扩展身份与文件夹，替换文件后对同一扩展点“重新加载”，刷新视频页并重新启用。不要为了更新卸载旧扩展；卸载可能删除收藏。必要时先导出词本。旧字段兼容读取，不会自动查询词本。

同页切换视频受支持；完整刷新后需要再点扩展图标。首次新视频获取失败时，按提示正常选择原生 CC 轨，必要时“重新获取”。无字幕或不可用翻译不能补造。YouTube 原生全屏仍待真实验收。仅支持普通 watch 页面，不支持 Shorts、直播、嵌入/移动页和视频元素单独全屏。
