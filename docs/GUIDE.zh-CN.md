# 使用与语言指南

适用于 **0.4.0 实验预发布版**。[返回首页](../README.zh-CN.md) · [English](GUIDE.md)

## 先区分三种语言

| 项目 | 0.4.0 的行为 | 是否可以选择 |
| --- | --- | --- |
| 插件界面：菜单、按钮、提示 | 固定简体中文 | 暂不支持切换，也不读取电脑或浏览器语言来切换 |
| 原文字幕 | 使用当前视频可用的 YouTube 字幕轨 | 在“原文字幕轨”中选择 |
| 译文字幕 | 优先使用目标语言的现有字幕；否则尝试 YouTube 提供的翻译 | 在“译文语言”中选择，受当前视频可用语言限制 |
| 查词释义 | 主释义语言跟随译文目标 | 没有独立的词典语言选择器；当前仅支持英文原词的中文、英文释义 |

因此，把译文改为英文不会把设置菜单改为英文。修改 Windows、macOS 或浏览器语言，也不会让本版本的界面自动换语言。“自动翻译字幕”与“自动识别界面语言”是不同功能。

## 默认语言与保存

第一次使用时，译文目标为简体中文（zh-Hans），并非从电脑语言推断。插件会优先读取本地已保存的译文目标；如果已保存目标未出现在当前视频的元数据中，插件会保留该选择并标注“此视频未提供”，不会自动切换成另一种语言；目标出现在下拉框中不保证该视频能提供对应内容。原文优先使用用户当次选择或同一视频短期记住的轨道；否则使用 YouTube 元数据提供的默认轨道，没有有效默认轨时，优先非自动识别轨，再回退到第一条可用轨。

字幕目标和布局写入浏览器本地存储。跨浏览器同步没有实现，真实浏览器重启后的保存恢复仍待验收；不要把代码中的保存逻辑当成已经完成的真实测试。

## 如何选择字幕与查词语言

1. 在普通 YouTube watch 视频页点击扩展图标，打开“上下字幕 · 设置”，在底部核对版本 0.4.0。
2. 选择“原文字幕轨”，再选择“译文语言”。原文默认在下、译文在上，可用“原译上下互换”调整。
3. 保持需要的字幕层可见。拖动模式显示的是位置示例；关闭拖动模式后再检查真实字幕。
4. 点击英文字幕中的单词，查看释义并按需要保存笔记与收藏。主释义按下表处理：

| 译文目标 | 查词结果 |
| --- | --- |
| 中文 | 中文释义与英文原文解释；中文保留来源原有简繁 |
| 英文 | 一个英文释义 / 原文解释区块 |
| 其他语言 | 提示目标词典暂不支持，并保留可用的英文原文解释 |

词典仍可能没有该词条或遇到网络失败。非英文原词会明确提示不支持。切换字幕目标会取消尚未完成的查词并切换显示；打开词本或复习不会自动联网查询。

## 功能一览

| 功能 | 用法与边界 |
| --- | --- |
| 两层字幕 | 分别调整位置、字号、背景颜色与不透明度、显隐、时间偏移 |
| 精听 | 上一句、下一句、单句重播、句末暂停、点击句子跳转 |
| 字幕文件 | 本地导入 / 导出 SRT、VTT；导入文件用于当前视频，不上传或自动翻译 |
| 生词与复习 | 保存单词、原句、视频时间点和手写笔记；掌握标记、重听、JSON / CSV 导出 |
| 语言来源 | 字幕和翻译来自 YouTube；英文词义来自公开维基词典 |
| 支持页面 | 桌面版普通 watch 页面；不支持 Shorts、直播、嵌入 / 移动页 |

## 看不到译文时

先检查“显示顶部字幕 / 显示底部字幕”和所选语言，再阅读设置中的状态提示。某些视频没有目标字幕或可用翻译，插件不能补造内容。

若提示“YouTube 未返回字幕内容”，按页面提示在 YouTube 原生 CC 正常选择对应字幕轨，再点击“重新获取”。这只是可能的恢复步骤，不代表自动获取已通过验收。同页换片、自然自动播放和首次打开未缓存视频的真实效果仍需验证。

完整刷新页面后，需要再点扩展图标启用。已有安装的更新步骤见[安装与更新](INSTALL.zh-CN.md)，更新前可先导出生词本。

## 验证状态

已发布的测试记录是 **54 项单元测试、24 组隔离 UI 测试**；这些不是本指南更新时重新运行的结果。0.4.0 在真实已安装 Chrome / Edge 中的验收仍不完整，尤其是首次新视频、自然自动播放、原生全屏、句末暂停精度和浏览器重启后的保存恢复。详见[验证范围](VALIDATION.zh-CN.md)。
