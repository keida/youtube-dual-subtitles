# 使用与语言指南

适用于 **0.5.0 实验预发布版**。[返回首页](../README.zh-CN.md) · [English](GUIDE.md)

## 先区分三种语言

| 项目 | 0.5.0 的行为 | 是否可以选择 |
| --- | --- | --- |
| 插件界面：菜单、按钮、提示 | 默认跟随浏览器；中文区域使用简体中文，其他区域使用 English | 可选择“跟随浏览器”“简体中文”“English” |
| 原文字幕 | 使用当前视频可用的 YouTube 字幕轨 | 在“原文字幕轨”中选择 |
| 译文字幕 | 优先使用目标语言的现有字幕；否则尝试 YouTube 提供的翻译 | 在“译文语言”中选择，受当前视频可用语言限制 |
| 查词释义 | 主释义语言跟随译文目标 | 没有独立词典语言选择器；仅支持英文原词的中文、英文释义 |

界面自动识别读取浏览器 UI 语言，不直接读取电脑系统语言；浏览器自身可能跟随电脑设置。手动选择优先于自动识别。切换界面语言不会翻译字幕、词典正文或你的笔记。“自动翻译字幕”与“自动识别界面语言”是不同功能。

## 默认语言与保存

第一次使用时，译文目标为简体中文（zh-Hans），并非从电脑语言推断。插件会优先读取本地已保存的译文目标；如果已保存目标未出现在当前视频的元数据中，插件会保留该选择并标注“此视频未提供”，不会自动切换成另一种语言；目标出现在下拉框中不保证该视频能提供对应内容。原文优先使用用户当次选择或同一视频短期记住的轨道；否则使用 YouTube 元数据提供的默认轨道，没有有效默认轨时，优先非自动识别轨，再回退到第一条可用轨。

界面语言、字幕目标和布局写入浏览器本地存储。跨浏览器同步没有实现，真实浏览器重启恢复仍为 NOT RUN。“恢复默认布局”只恢复两层外观，不重置语言选择、时间偏移、显隐、原译顺序或句末暂停。

## 如何选择语言与查看释义

1. 主动决定安装或更新后，在普通 YouTube watch 页点击本扩展图标，打开设置，在底部核对版本 0.5.0。下载包 manifest 不能证明浏览器运行版本。
2. 在“界面语言”选择“跟随浏览器”“简体中文”或“English”。
3. 选择“原文字幕轨”，再选择“译文语言”。原文默认在下、译文在上，可用“原译上下互换”调整。
4. 保持需要的字幕层可见。拖动模式显示位置示例；关闭拖动模式后再检查真实字幕。字幕截断时可打开全文。
5. 点击单词会暂停并打开卡片。支持的英文原词可查询释义，笔记与收藏需主动保存。

| 英文原词的译文目标 | 查词结果 |
| --- | --- |
| 中文 | 中文释义与英文原文解释；中文保留来源原有简繁 |
| 英文 | 一个英文释义 / 原文解释区块 |
| 其他语言 | 提示目标词典暂不支持，并保留可用的英文原文解释 |

点击译文层时采用该层的语言，不再一律当英文查询。非英文原词明确提示不支持；导入原文没有已确认的来源语言，查词按未知语言处理。

词典正文支持鼠标选字。复制按钮同时复制释义、来源和许可；剪贴板写入失败会提示手动选中复制。每种词典语言独立等待最多 5 秒，某种失败时保留另一种语言的成功结果；有旧收藏释义时会保留并注明。词义来自词典，不是机器翻译。

切换字幕目标会取消尚未完成的查词并切换显示；打开词本、复习或恢复备份不会自动查询服务方。

## 功能一览

| 功能 | 用法与边界 |
| --- | --- |
| 两层字幕 | 分别调整位置、字号、背景颜色与不透明度、显隐、时间偏移；重叠时保留仍有效的字幕 |
| 精听 | 上一句、下一句、单句重播、句末暂停、点击句子跳转 |
| 字幕文件 | 本地导入 / 导出 SRT、VTT；用于当前视频，不上传或自动翻译 |
| 生词与复习 | 保存词、原句、视频时间点和手写笔记；掌握标记与重听 |
| 词本管理 | 搜索词/原句/笔记、每页 50 条、单条删除确认、JSON/CSV 导出及 JSON 预览合并恢复 |
| 小播放器 | 宽度低于 680 px 时设置与词卡互斥；完整字幕有单独视图 |
| 语言来源 | 字幕和翻译来自 YouTube，英文词义来自公开维基词典 |
| 支持页面 | 桌面版普通 watch 页；不支持 Shorts、直播、嵌入 / 移动页 |

字幕偏移正值延后、负值提前；跳句与重播按原文时间定位。收藏保留原句及原视频时间点。

## 笔记与安全备份恢复

笔记可以主动清空并保存，包括复习揭示后的笔记。后台串行、按字段更新收藏，保留其他标签对无关笔记、掌握状态或词典字段的更新。读取失败后先重试，读取成功前不能保存。此行为已有隔离回归，真实已安装多标签 MV3 整合仍为 NOT RUN。

可按单词、原句或笔记搜索并翻页；单条删除需再次确认。试用更新或恢复备份前，先导出当前 JSON。

恢复步骤：

1. 打开“从 JSON 备份恢复”，可先点“先导出当前备份”。
2. 选择版本 1–5、最多 16 MiB、5000 条的 JSON 备份。
3. 查看校验预览。无效条目、危险来源或 ID 冲突会被拒绝，不进行部分导入。
4. 点击“合并恢复”。只添加新项，已有重复项、笔记及掌握状态保持原样，不替换整个词本。
5. 等待完成结果；提交后禁止取消或换文件。

合并后的规范词本最多 4 MiB / 5000 条，超过限制整批拒绝。旧有合法但超过新容量的词本仍可读取、导出和缩减。CSV 用于阅读分析，JSON 才是恢复格式；导出含个人笔记及视频书签。

## 看不到译文与导入字幕时

先检查“显示顶部字幕 / 显示底部字幕”和所选语言，再阅读设置状态。某些视频没有目标字幕或翻译，插件不能补造内容。

两条轨分别恢复；自动恢复会保留成功轨，只重试失败轨。失效或空的原生请求会尝试有次数限制的正常 CC 加载。如果仍提示没有字幕内容，按提示在 YouTube 原生 CC 正常选择对应字幕轨，再点“重新获取”。手动重新获取会主动重载网络字幕。这些恢复流程不代表首次新视频或自然自动播放的真实获取已通过验收。

导入译文不会取消正在加载的原文；同视频重试保留导入，迟到的网络结果不会覆盖它。点击“清除导入字幕”主动移除，切换视频也会清空。

完整刷新页面后需要再点扩展图标。插件不会自动更新；替换现用安装前应先导出 JSON 并保留扩展身份。确认更新后，刷新**所有**仍运行旧版代码的 YouTube 标签，再启用新版；旧 0.4.0 页面仍会整表写词本。详见[安装与更新](INSTALL.zh-CN.md)。

## 验证状态

2026-10-22 的验证记录为 **80 项单元测试、24 组既有隔离 UI、20 个候选测试节点通过**。候选节点包含 5 个 VM 用例、7 组字幕浏览器场景、6 项界面语言测试，以及内部含 15 组场景的词本脚本；这是嵌套计数，不能相加当成独立验收总数。准确范围见[验证报告](VALIDATION.zh-CN.md)。

真实 YouTube 获取/同步、已安装 MV3 后台/隔离世界整合、实机多标签写入、原生全屏、自然自动播放、真实浏览器重启保存，以及长时间/后台/倍速播放精度仍为 **NOT RUN**。系统剪贴板、Linux、Edge、CI 也未运行。发布相同候选代码不会增加测试证据。
