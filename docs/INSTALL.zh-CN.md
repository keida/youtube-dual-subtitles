# 审阅、安装与更新

当前目录是 **0.5.0 实验预发布版**。下载或解压不会安装、重载或替换现用扩展，也不会覆盖已有词本。未配置从 0.4.0 自动升级。

## 先审阅

1. 插件 ZIP 与校验和的下载位置为 [v0.5.0 预发布页](https://github.com/keida/youtube-dual-subtitles/releases/tag/v0.5.0)。把 `YouTube-Dual-Subtitles-0.5.0-candidate-extension.zip` 解压到独立目录；`extension` 子目录含 `manifest.json`。
2. 查看候选说明与[验证报告](VALIDATION.zh-CN.md)，核对附带的校验和。
3. 保留现用 0.4.0 及原文件。任何后续替换前，先在现用词本导出当前 JSON 备份。
4. 审阅后另行决定是否安装。替换正在使用的版本需要用户确认。

## 决定安装后

安装和扩展管理由用户手动操作。若使用独立测试浏览器配置，通过浏览器的开发者扩展加载功能选择候选 `extension` 目录。测试配置有自己的存储，不会自动带入现用配置的词本。

若已确认更新现有安装，应保留同一扩展身份和可回退的原文件。确认替换完成后，重载同一扩展，再刷新所有曾启用旧版的 YouTube 标签，然后重新点击扩展图标。旧 0.4.0 页面脚本仍会整表保存词本，不能让它与新版后台写入同时运行。不要为了更新先卸载；卸载可能删除本地数据。

在普通、可访问的 `www.youtube.com/watch` 页打开本插件设置，查看底部版本。下载包 manifest 显示 0.5.0，并不代表浏览器已加载它。Language Reactor 等其他扩展的界面不能作为本插件运行证据。

## 候选版操作

- 界面语言可选“跟随浏览器”“简体中文”或“English”；自动选项读取浏览器界面语言，不直接读取系统。
- 选择原文字幕轨与译文目标，可用内容来自 YouTube。
- 自动恢复只重试失败轨，保留同一视频、同一选轨下已成功的另一轨。“重新获取”会主动重新读取网络字幕；本地导入仍保留。如果自动获取仍失败，按页面提示正常使用原生 CC，再重试。
- SRT/VTT 导入仅用于当前视频；重新获取保留导入，“清除导入字幕”主动移除，切换视频时清空。
- 点击受支持英文词暂停并查词。可直接选中释义或点击复制；复制包含来源和许可。笔记需主动保存。
- 词本可搜索和翻页；删除有二次确认。JSON 恢复先预览，点击“合并恢复”才写入，已有重复项保持原内容。
- “恢复默认布局”只重置两层外观，保留语言、时间偏移和其他学习偏好。

关闭覆盖层会清理监听和计时，并恢复临时调整的原生 CC；完整刷新网页后需要再点扩展图标。支持普通 watch 页；Shorts、直播、嵌入、移动页和视频元素单独全屏不在支持范围。YouTube 原生全屏仍需真实验收。
