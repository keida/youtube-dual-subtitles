## 关键证据

- 两个隔离页面共用实际 vocabulary-store 仓库，同时收藏及更新笔记、掌握状态、词典字段，保留无关修改。后台发送者检查另有 VM 测试。浏览器传输和存储 API 使用模拟实现。
- 在祖先 user-select:none 下，真实鼠标拖选成功选中中文释义；使用实际候选 CSS。复制成功和拒绝均测试，剪贴板 API 使用模拟实现，未读取或改写系统剪贴板。
- 英文词典请求实际等待到默认 5 秒超时后，成功的中文释义仍显示。外部响应为合成数据，不代表当前 Wiktionary 可用性。
- 合法 5000 条词本为 3,556,671 字节，导出 JSON 为 4,315,710 字节。该备份预览后成功恢复到空测试存储，修订号从 0 变为 1。16 MiB 用于输入文件限制，4 MiB / 5000 条用于规范词本。
- 恢复提交后禁用取消和换文件；强制派发相应事件也不会隐藏完成结果。无效版本、条目、危险来源、过大文件或过多条目不会写入。
- 自动恢复保留同视频、同选轨的成功字幕。双向交替失败均测试，成功轨没有再次请求，也没有闪空。手动“重新获取”仍主动重载网络轨并保留本地导入。
- 界面语言只改变控件与提示，字幕、词典正文、原句、词名、笔记及删除确认中的原词/时间保持不变。

独立审查发现的“大备份无法恢复”“提交后取消误报”“自动恢复清掉成功字幕轨”三项均已修复并复核关闭。

## NOT RUN 与限制

上述验证环境没有可读取用户 Chrome 标签的受支持浏览器/桌面界面。设备在线与文件/进程能力不等于浏览器控制能力。验证没有操作扩展管理页，也没有要求重复安装或授权。

以下均为 **NOT RUN**：真实 YouTube 双轨获取与同步、真实 MV3 后台/隔离世界整合、用户 Chrome 中双标签写入、原生 YouTube 全屏、自然自动播放下一视频、浏览器重启后的持久化、长时间/后台/倍速播放精度，以及系统剪贴板。Linux、Edge、其他浏览器版本与 CI 也未运行。

夹具中的 DOM Fullscreen、模拟导航/自动播放、新文档注入已保存对象，都只验证隔离逻辑，不能替代以上真实验收。测试没有使用个人浏览器配置、真实收藏、真实字幕授权参数或联网请求。

实验预发布仍需用户决定是否安装。后续替换现用安装须另行确认，先导出当前 JSON，并刷新所有仍运行旧版的 YouTube 标签；见[安装说明](INSTALL.zh-CN.md)。
